## 🔗 What is LangChain?

LangChain is a framework for building applications powered by Large Language Models (LLMs).

It provides useful components for working with:

- LLMs
- Chat Models
- Prompts
- Messages
- Retrievers
- Tools
- Agents
- Vector Stores
